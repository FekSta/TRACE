# TRACE System Diagrams

This folder contains Mermaid-based diagrams for the TRACE Lost & Found Management System.

## Diagrams Included

| Diagram | File | Description |
|---|---|---|
| **Entity Relationship Diagram** | `data-model.md` | Database schema showing all entities and their relationships |
| **Use Case Diagram** | `use-case.md` | System actors and their use cases |
| **Process Model** | `process-model.md` | Business process workflows and component interactions |

## Viewing the Diagrams

These diagrams use [Mermaid](https://mermaid.js.org/) syntax. You can view them:

- **GitHub**: GitHub renders Mermaid natively in `.md` files
- **VS Code**: Install the [Mermaid Preview](https://marketplace.visualstudio.com/items?itemName=bierner.markdown-mermaid) extension
- **Online**: Paste into the [Mermaid Live Editor](https://mermaid.live/)
- **CLI**: Use `npx @mermaid-js/mermaid-cli` to render to PNG/SVG
